KEY RESEARCH FINDINGS
================================================================================

EHR MARKET LANDSCAPE (2026):
- Epic: 42.3% acute care share, $100K+, 6-12 months
- Cerner/Oracle Health: 22.9% acute care share, $100K+, 6-12 months
- Athenahealth: Dominant ambulatory, $30K, 2-4 months (fastest)
- eClinicalWorks: 150K+ providers, $20K, 2-4 months
- NextGen: Powers 1/3 of HIEs, $20K+, 2-4 months
- Greenway Health: Specialty focus, $15K, 2-4 months
- AdvancedMD: Independent practices, $15K, 2-4 months

TECHNICAL STANDARDS (MANDATED BY 2026):
- FHIR R4 API read endpoints
- SMART on FHIR v2.2.0
- OAuth 2.0 with PKCE
- Bulk data export ($export)
- USCDI v3 data elements
- <3 second response time (95th percentile)

CRITICAL HCC DATA SOURCES:
- Condition resources (ICD-10 diagnoses)
- Encounter resources (visit validation)
- Observation resources (disease severity)
- DiagnosticReport resources (clinical findings)
- RiskAssessment resources (HCC probabilities)

INTEGRATION STRATEGIES:
Option 1: Point-to-Point (NOT recommended)
  - Cost: $300-400K, Timeline: 18+ months, Scalability: Poor

Option 2: Unified Platform (RECOMMENDED)
  - Cost: $200-400K + $5-10K/month, Timeline: 3-6 months, Scalability: Good
  - Tech Stack: FHIR Server (HAPI) + ETL (Airflow) + Warehouse (Snowflake)

Option 3: Third-Party Vendor
  - Cost: $500-5K/month, Timeline: 1-2 months, Scalability: Vendor-dependent
  - Vendors: Redox, Veradigm, InterSystems, 1upHealth
