## 🎨 Key Specifications At a Glance

### Color Palette
```
Primary:         #0057ff (professional blue)
Success:         #198754 (clinical green)
Danger:          #dc3545 (alert red)
Warning:         #ffc107 (caution amber)
Light BG:        #f4f6f9 (light blue-gray)
Dark Sidebar:    #343a40 (dark gray)
Card:            #ffffff (white)
```

### Layout
```
Sidebar width:   280px (fixed)
Header height:   56-64px
Spacing unit:    16px (base - 8px/24px/32px variants)
Typography:      14px (body default)
Border radius:   4-8px (clinical feel)
```

### Risk Visualization
```
High Risk:       #dc3545 (Red) - Requires action
Medium Risk:     #ffc107 (Amber) - Monitor
Low Risk:        #20c997 (Green) - Normal
Baseline:        #adb5bd (Gray) - Healthy
```

### Components
```
Patient card:    100px tall, avatar + name + risk badge
Risk score:      140x140px centered gauge
Vital tile:      150x180px grid (12-tile layout)
Badge:           24-28px tall, color-coded
Alert card:      Full width, left border + colored background
```
