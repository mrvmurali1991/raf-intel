## Key Industry Standards Referenced

- **CMS HCC Models:** Versions 22-28+; updated annually with weight adjustments
- **HIPAA Privacy and Security Rules:** 45 CFR Parts 160 and 164
- **MEAT Documentation Standard:** Monitoring, Evaluation, Assessment, Treatment requirements for condition capture
- **ICD-10-CM Coding Standards:** Current diagnosis coding requirements for RAF capture
- **CPT Code G0136:** New SDOH assessment reimbursement code effective January 2026
- **RADV Program:** CMS Medicare Advantage Risk Adjustment Data Validation audit program
- **Safe Harbor Deidentification:** 18-identifier removal standard for HIPAA de-identification
