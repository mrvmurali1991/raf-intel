AUTHENTICATION FLOW
================================================================================

Step 1: User Authorization
  Redirect to: https://openemr.ehrservicedesk.com/oauth2/default/authorize
  With: client_id, redirect_uri, response_type=code, scope, state, code_challenge

Step 2: Authorization Code
  User logs in to OpenEMR
  System redirects: http://localhost:3000/emr-config/callback?code=...&state=...

Step 3: Token Exchange
  POST to: https://openemr.ehrservicedesk.com/oauth2/default/token
  With: grant_type=authorization_code, code, client_id, code_verifier

Step 4: FHIR API Access
  Use access_token in Authorization header for all FHIR queries
